# SET/LAB

Constructor personal de sets de techno con IA: subís tus temas, escribís cómo querés que
sea el set y se arma solo, con transiciones de DJ, para escucharlo en un reproductor estilo
Mixxx y compartirlo con un link que vence a los 7 días.

| Carpeta | Contenido |
| --- | --- |
| `CLAUDE.md` | Contexto completo para Claude Code (decisiones, estado, aprendizajes) |
| `docs/plan.md` | Plan del proyecto: estudio de mercado, arquitectura, fases |
| `docs/historial.md` | Cómo se llegó a cada decisión |
| `docs/diseno/` | Diseño de las 3 pantallas (abrir los `.dc.html` como referencia) |
| `docs/fase0/` | Resultados y aprendizajes de la prueba de sonido |
| `fase0/` | Script de transición entre dos temas (funciona) |
